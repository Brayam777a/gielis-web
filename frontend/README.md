# Frontend (React + TypeScript)

Esta carpeta se crea con Vite. Desde la raíz del repo:

```bash
npm create vite@latest frontend -- --template react-ts
cd frontend
npm install
npm run dev
```

Vite preguntará si la carpeta no está vacía: elige **Ignore files and continue**
(este README se reemplaza). Si ves la página de Vite en
`http://localhost:5173`, está listo.
